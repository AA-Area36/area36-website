Five highest-priority actions

1. Upgrade Next.js
Move from 16.1.6 to a compatible patched 16.2.x release (at least 16.2.6), then run Next/OpenNext and routing/auth regression checks.
2. Gate flyer mutations

2. Release blockers and immediate actions

Two confirmed release blockers.
  1. DEP-001: the directly reachable Next.js 16.1.6 release is affected by middleware/App Router bypass and RSC denial-of-service advisories.
  2. SEC-001: public Server Actions delete/reorder event flyers without authorization.

Immediate action: restrict exposure or deployment until both are remediated and the listed negative/regression checks pass. No Critical blocker was found.
