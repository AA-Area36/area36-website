# Plan: Lazy Load GDrive Files via API

## Goal
Detach Google Drive fetching from page rendering. Pages load instantly without files, then lazy load via a dedicated API endpoint with detailed logging for debugging.

## Architecture Change

```
BEFORE (SSR blocking):
Page Request → Server Component → GDrive API (40+ calls) → Render HTML
              └── BLOCKS PAGE LOAD ──────────────────────┘

AFTER (Lazy load):
Page Request → Server Component → Render HTML (with skeleton)
                                        ↓
              Browser → API /api/gdrive/[type] → GDrive API → JSON
                                        ↓
              Client Component → Display Files
```

## Files to Modify

### 1. Create Unified GDrive API Route
**New file:** `app/api/gdrive/[type]/route.ts`

Handles all GDrive fetching with detailed logging:
- `GET /api/gdrive/recordings` - fetch recordings
- `GET /api/gdrive/newsletters` - fetch newsletters  
- `GET /api/gdrive/resources` - fetch resources
- `GET /api/gdrive/committees` - fetch committee files
- `GET /api/gdrive/service-resources` - fetch service resources
- `GET /api/gdrive/conference-materials` - fetch conference materials

Logging includes:
- Request start time
- Each GDrive API call duration
- Total request duration
- Error details with stack traces
- Folder IDs being accessed

## API Route Implementation Details

```typescript
// app/api/gdrive/[type]/route.ts
export async function GET(request, { params }) {
  const { type } = await params
  const startTime = performance.now()
  const requestId = generateRequestId()
  
  console.log(JSON.stringify({
    level: "info",
    requestId,
    message: "GDrive API request started",
    type,
    timestamp: new Date().toISOString(),
  }))
  
  try {
    let data
    switch (type) {
      case "recordings":
        data = await fetchRecordingsData(requestId)
        break
      case "newsletters":
        data = await fetchNewslettersData(requestId)
        break
      // ... etc
    }
    
    const duration = performance.now() - startTime
    console.log(JSON.stringify({
      level: "info",
      requestId,
      message: "GDrive API request completed",
      type,
      durationMs: Math.round(duration),
      itemCount: Array.isArray(data) ? data.length : Object.keys(data).length,
    }))
    
    return Response.json(data)
  } catch (error) {
    const duration = performance.now() - startTime
    console.error(JSON.stringify({
      level: "error",
      requestId,
      message: "GDrive API request failed",
      type,
      durationMs: Math.round(duration),
      error: error.message,
      stack: error.stack,
    }))
    
    return Response.json({ error: error.message }, { status: 500 })
  }
}
```

## Benefits

1. **Instant page loads** - No blocking on GDrive
2. **Better debugging** - Clear logs show exactly where time is spent
3. **Isolated failures** - GDrive issues don't crash page loads
4. **Better UX** - Users see content structure immediately with loading indicators
5. **Easier testing** - Can test API endpoint independently
