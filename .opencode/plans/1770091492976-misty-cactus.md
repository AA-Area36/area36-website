# Recurring Events Implementation Plan

## Overview

Add support for recurring events with:
- **Single parent record** with virtual instances generated on-the-fly
- **Weekly + Monthly** recurrence patterns
- **Individual exceptions** - modify or cancel specific occurrences
- **Recurring until date** - required end date for recurring events

### 2. Recurrence Patterns

**Weekly:**
- Store array of day numbers `[0-6]` (Sunday=0)
- Example: `[2]` = every Tuesday

**Monthly:**
- **Day of Month:** Store day number (1-31)
  - Example: `15` = 15th of every month
- **Day of Week:** Store `{week: 1-5, day: 0-6}`
  - Example: `{week: 2, day: 2}` = 2nd Tuesday
  - `week: 5` = "last" occurrence

## Edge Cases

1. **Multi-day recurring events:** Calculate duration from parent, apply to each occurrence
2. **Monthly "31st":** Skip months without 31 days
3. **"Last Tuesday":** Calculate from end of month backwards
4. **Max duration:** Limit recurring events to 2 years
5. **Performance:** Only generate occurrences for requested date range
